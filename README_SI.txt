MOHOMAD XMD - AI HACKER WEBSITE
================================

අවශ්‍ය දේ:
- GitHub account එකක්
- Railway account එකක්
- Android phone එකක් සහ internet

Project files:
- server.js          Node.js / Express server
- package.json       Dependencies සහ start command
- railway.toml       Railway deploy settings
- public/index.html  Website structure
- public/style.css   Black + Gold design
- public/script.js   Chat interaction
- .gitignore         අනවශ්‍ය files GitHub වෙත නොයැවීමට

ANDROID PHONE එකෙන් GITHUB UPLOAD කරන හැටි:
1. ZIP එක extract කරන්න.
2. GitHub වෙබ් අඩවියට login වෙන්න.
3. New repository තෝරන්න.
4. Repository name: moh omad-xmd-ai-hacker (හිස්තැන් නැතුව: mohomad-xmd-ai-hacker)
5. Public හෝ Private තෝරලා Create repository කරන්න.
6. Add file > Upload files තෝරන්න.
7. ZIP එකේ ඇතුළත files/folders සියල්ල upload කරන්න. ZIP එකම upload කරන්න එපා.
8. Commit changes ඔබන්න.

RAILWAY DEPLOY:
1. railway.app වෙත ගොස් GitHub account එකෙන් login වෙන්න.
2. New Project තෝරන්න.
3. Deploy from GitHub Repo තෝරන්න.
4. mohomad-xmd-ai-hacker repository එක තෝරන්න.
5. Deploy එක අවසන් වනතුරු ඉන්න.
6. Railway project එකේ Settings > Networking / Public Networking වෙත යන්න.
7. Generate Domain ඔබන්න.
8. ලැබෙන railway.app link එකෙන් website එක බලන්න.

සටහන්:
- Railway එක PORT environment variable එක ලබාදෙන නිසා PORT එක අතින් සකස් කරන්න අවශ්‍ය නැහැ.
- package.json නිසා Railway npm dependencies install කරයි.
- /health endpoint එක health check සඳහා භාවිතා වේ.
- මේ project එකේ AI chat එක DEMO MODE පමණයි. සැබෑ AI සේවාවක් නැහැ.
- සැබෑ AI API එකක් එක් කරන විට API key එක server-side environment variable එකක තබන්න. HTML/JavaScript හෝ GitHub වෙත API key එක දාන්න එපා.
- Contact email එක public/index.html තුළ hello@example.com ලෙස placeholder එකක්. ඔබේම contact email එකක් යොදන්න.
